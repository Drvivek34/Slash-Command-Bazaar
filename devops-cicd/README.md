## How entries are stored
Each slash command lives in **its own sub-folder** inside this category, named in `kebab-case`:

```
devops-cicd/
└── <entry-name>/
    ├── README.md     # what it is, source, author, license, link
    └── ...           # the actual files (full copy)
```
