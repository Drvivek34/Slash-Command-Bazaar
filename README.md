# ⚡ Slash Command Bazaar

> A collection of slash commands for Claude Code and other AI CLIs.

[![Mega AI Bazaar](https://img.shields.io/badge/🌐_Mega_AI_Bazaar-browse_all-6C5CE7)](https://drvivek34.github.io/Mega-AI-Bazaar/) [![Submit](https://img.shields.io/badge/➕_Submit-a_slash_commands-2ecc71)](https://github.com/Drvivek34/Slash-Command-Bazaar/issues/new/choose) [![License](https://img.shields.io/badge/License-MIT-blue)](LICENSE)

Slash Command Bazaar collects **slash commands** — reusable `/command` definitions for Claude Code and other AI coding CLIs — into one categorized set. The handiest commands are surfaced in **featured/**.

## 📂 Categories

**[⭐ Featured](featured/)** — top picks, surfaced at the very front.

| Category | About |
|---|---|
| [AI & Prompts](ai-prompts/) | Commands that orchestrate prompts and agents. |
| [Backend](backend/) | Commands for APIs, services, and data layers. |
| [Code Review](code-review/) | Commands for reviewing diffs and PRs. |
| [Database](database/) | Commands for migrations, queries, and schema. |
| [Debugging](debugging/) | Commands for repro, triage, and root-cause. |
| [DevOps & CI/CD](devops-cicd/) | Commands for deploys, pipelines, and infra. |
| [Documentation](documentation/) | Commands for docs, READMEs, and comments. |
| [File Operations](file-operations/) | Commands for bulk edits and file wrangling. |
| [Frontend](frontend/) | Commands for UI, components, and styling. |
| [Git & Version Control](git-version-control/) | Commands for commits, branches, PRs, and history. |
| [Miscellaneous](misc/) | Everything that doesn't fit a category yet. |
| [Productivity](productivity/) | Commands for personal workflow shortcuts. |
| [Project Management](project-management/) | Commands for issues, planning, and standups. |
| [Refactoring](refactoring/) | Commands for cleanup, renames, and restructuring. |
| [Security](security/) | Commands for audits and security review. |
| [Testing](testing/) | Commands for generating and running tests. |

## 🗂️ How it's organized
Every slash commands lives in its **own sub-folder** inside a category, with a `README.md` recording its **source, author, and original license** (a full copy of the files is kept). See **[CONTRIBUTING.md](CONTRIBUTING.md)**.
